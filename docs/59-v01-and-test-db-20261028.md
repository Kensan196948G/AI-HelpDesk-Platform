## 2. テスト DB の再作成

| 項目 | 値 |
|---|---|
| 原因 | `ai_helpdesk_test` の `tickets` が 430 件に累積し、`/api/desk/queue` の `LIMIT 100`（signal 昇順・作成日時昇順）から新規チケットが漏れていた（コード起因ではない） |
| 対応 | `DROP DATABASE ai_helpdesk_test WITH (FORCE)` → `CREATE DATABASE`（テスト専用 DB） |
| 結果 | `npm run test` = **514/514 PASS**（56 files）。以前は 507/508（1 failed） |

- 本番 DB・検証 DB には影響なし。テスト実行時に migrate/seed が自動で走る。
