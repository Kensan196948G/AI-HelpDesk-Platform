## 4. 検出した問題

### F1（中）: 根拠なしの相談で `sources` に無関係な KB が残る

- 事象: AI-09（経費精算の締め日）で、回答は正しく「該当なし・担当者へ」だが、`sources` に **KB-2026-0006 / 0009 / 0001** が返る（3 回とも同じ）。
- 影響: 画面が `sources` を「根拠」として表示すると、無関係な KB を根拠に見せる。回答本文は「いずれも本件と無関係」と補足しているが、構造として不整合。
- 原因: `sources` は検索結果（上位候補）であり、モデルが実際に引用した KB ではない。
- 対策案:
  1. 回答中の `根拠: KB-...` を解析し、**実際に引用された KB だけ**を `sources` にする。
  2. 併せて検索スコアの下限を設け、該当なしなら `sources: []` を返す。
  3. UI は「根拠」と「参考候補」を分けて表示する。

### F2（低）: 回答が 600 字をわずかに超過

- 事象: AI-04 の 1 回が **604 字**（システムプロンプトは 600 字以内）。
- 影響: 表示上の軽微な超過。禁止事項ではない。
- 対策案: プロンプトの上限を 560 字程度にし、余裕を持たせる。
