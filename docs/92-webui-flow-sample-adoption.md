# 92. WebUI サンプル（対応フロー版）と画面仕様書の追加・取り込み方針（2026-11-11）

## 0. 結論

オーナー指示（2026-11-11、選択「1,2」）に基づき、次の 2 つを行った。

1. **段階 0（本 PR）**: 完全オフラインのサンプル WebUI と画面仕様書 2 点をリポジトリに追加した。**配信中の WebUI は変更しない**（既存の受入・リリース判定に影響なし）。
2. **段階 1 の計画**: 比較版の評価に基づき、取り込み候補を「新画面・ブリッジとして追加する」方針で計画化した（§3）。実装は別 PR。

**重要**: サンプルは**そのまま置換できない**。認証（操作者選択）、保存（localStorage）、AI・PC 情報・リモート対応（すべて疑似）が既存と異なり、特に「AI が相談者 PC の修復を実行する」機能は [docs/68](68-release-rc-20261102.md) の No-Go 判定と衝突する。

## 2. 確定した判断（オーナー選択: 推奨既定）

| # | 事項 | 決定 |
|---|---|---|
| 1 | サンプルの位置づけ | **(a) 既存に新画面として追加**（既存画面の置換はしない） |
| 2 | リモート対応 | **(a) 対話形式の表示だけ採用し、実行は既存経路**（AI による修復実行は取り込まない） |
| 3 | PC 情報の取得と同意 | **(a) 既存どおり自動取得＋共有時に本人が選ぶ** |
| 4 | 困りごとの分類 | **(a) 既存の 6 種にそろえる** |
| 5 | AI 検査の位置づけ | **(a) 参考表示にとどめる**（点数で承認申請の可否を決めない） |
| 6 | ログアウト | **(a) 設けない**（共有 PC 要件が生じた場合のみ Access ログアウトへ誘導） |

この決定により、[AGENTS.md](../AGENTS.md) §7 の「原本 HTML を 100% 適用し、DOM・CSS・画面遷移を変えない」方針は**維持**される。取り込みは「新画面・ブリッジの追加」として行う（前例: 引継ぎワークスペース [docs/33](33-handover-workspace.md)）。

## 3. 段階 1: 取り込み計画（新画面・ブリッジ）

### 3-1. 対象（比較版 §7 の「可／条件付き可」から）

| # | 機能 | 方式 | 条件 |
|---|---|---|---|
| 1 | 右詳細パネルの 1 ページ化（タブ・固定フッター） | **新画面**として追加（担当者向け）。既存の引継ぎワークスペースとの役割重複を整理 | 原本 HTML は変更しない |
| 2 | 手順の繰り返し試行の一覧・試行済み表示 | ブリッジ（STEP 3） | 候補は「別アカウントが承認したナレッジ」に限定。「解決しなかった」の集計はサーバー保存が前提 |
| 3 | 承認ボタンの制御・チェック進捗 | ブリッジ（SC-06 相当） | 承認の正当性はサーバー検査のまま |
| 4 | AI 検査の指摘表示 | ブリッジ（参考表示） | 検査規則はサーバーの伏せ字・承認検査と同じ正本。点数は参考 |
| 5 | 承認後の「今回反映」強調 | ブリッジ（ナレッジ DB 一覧） | 表示のみ |
| 6 | PC 診断の「PC情報からの補足」 | 条件付き | ★表示と重複しないようルールの正本を一本化。AI へ渡す情報から IP・シリアル等を除く既存方針を守る |
| 7 | 入力中のリアルタイム判定 | 条件付き | 代行受付のみ。**ルールベース**に限定し、実 AI を毎回呼ばない |

### 3-2. 取り込まないもの（明示）

- ログイン画面（操作者選択）— Cloudflare Access に置き換わる
- AI による修復の実行・リモート接続 — [docs/68](68-release-rc-20261102.md) の No-Go。覆す場合は別設計・明示承認（R4）
- localStorage を正本とする保存 — 既存は PostgreSQL
- 同意の段階を省く引継ぎ — 既存の STEP 4 の同意を維持
- 7 分類への変更 — 既存の 6 種にそろえる

### 3-3. 実装フェーズ（各フェーズ 1 PR）

| フェーズ | 内容 | 検証 |
|---|---|---|
| PR-1 | 新画面（右詳細パネル）の骨格＋読み取り専用データ | `typecheck` / `lint` / `test` / UI スモーク（スクショ） |
| PR-2 | ブリッジ: 手順の繰り返し試行一覧・承認ボタン制御・AI 検査指摘 | 既存テスト＋追加テスト、UI スモーク |
| PR-3 | 表示改善: 「今回反映」強調・PR-1 の仕上げ | UI スモーク、受入 UI の再実行 |
| 受入 | UI 系（#5 / #8 / A05 / A08a 等）の再実行 | レポート v5、新しいリリース判定（既存の条件付き GO は `7573784` に対する履歴） |
