# 同じ実端末の結果から次の相談まで（2026-11-01、`ae9bcce`）

結果の読み方は [docs/65 §0-1](../../65-readme-dataflow-map.md)。ここは記録だけを置く。

- `result.json`: 段ごとの結果、ID、API の記録、拒否の確認。トークン、キー、トンネルの URL は含まない。
- `audit-counts.txt`: 監査ログの件数。
- `*.png`: 画面。ヘッドレスのブラウザで、端末の欄はサーバの情報である。

検証 DB、トンネル、端末のタスク、エージェント、トークン入りの設定は実行の後に削除した。

RSP の `command_logs` には導入コマンドが残る。デバイストークンは含まない。ファイルの取得キー、1 回限りの設定取得キー、一時トンネルの URL は含むが、キーは使用済みか、トンネルの停止で使えない。
