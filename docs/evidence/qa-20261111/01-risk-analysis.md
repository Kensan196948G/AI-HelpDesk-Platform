## 4. 今回の QA では除去できない残リスク

- 実 Cloudflare Access OTP 後の画面・API（人間の OTP が必要）
- 実 Windows 端末・実貸与・実社員・別人物承認（Issue #121）
- 本番 DB への書込み、本番/staging への配備、systemd の状態変更
- 外部 AI（DeepSeek）の実回答品質・幻覚（stub では検証不能）
- 遠隔支援のサーバ側同意セッション（実装されていない）
- CSRF トークンなし（SameSite=Lax + Origin 検証で代替。docs/07 §7）
- 負荷・長時間運用・災害復旧の実地試験
