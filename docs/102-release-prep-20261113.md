## 4. 見つかったこと

### 4-1. 共有のテスト DB `ai_helpdesk_test` では 1 件失敗する

最初に `.env.test.local` の `ai_helpdesk_test` で全テストを実行したところ、**119 files 中 1 file / 2202 tests 中 1 test が失敗**した。

- 失敗: `apps/api/src/lib/knowledge-search.integration.test.ts`「期待される KB を、下限で落とさない」。
  相談 `kb-10`（共有フォルダ）の期待 `KB-2026-0001` が上位 3 件から押し出された。
- 原因: この DB には過去の試験が作った `knowledge` が残っている（`approved` 89 件 / `draft` 40 件。シードは 9 件）。
  「共有フォルダ」を題にした承認済み KB が多数あり、検索の上位を占める。
- 新規 DB では同じテストが pass する（§3）。CI も毎回新しい DB を使うので緑である。**製品コードの回帰ではない。**
- 今回の全テスト実行も、この DB に migrate・seed・試験データを書き込んでいる。
- 対処は未実施。この DB を作り直すか、ローカルの全テストは毎回新規 DB で行う運用にするかは別途決める。
