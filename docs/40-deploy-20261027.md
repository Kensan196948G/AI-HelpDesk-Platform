### 8-2. インシデント（サービス停止 約3分）

- **事象**: 11:44 の再起動で `ai-helpdesk-api` が起動失敗（`ERR_MODULE_NOT_FOUND: Cannot find package 'dotenv'`）。原因は、作業中にメインリポジトリの `node_modules` が**自分自身へのシンボリックリンク**（`node_modules -> .../AI-HelpDesk-Platform/node_modules`）に置き換わっていたこと。

- **復旧**: 壊れたリンクを削除 → `npm ci`（`package-lock.json` どおり再構築・exit 0）→ `npm run build` → 再起動。health 200 を確認。
- **原因**: 特定できていない（worktree の `node_modules` をシンボリックリンクで共有する作業中に、メインリポジトリ側でリンクが作られた可能性）。**証跡上の事実**として記録する。
- **再発防止（提案）**: デプロイ手順の先頭に「`node_modules` が実ディレクトリであること（シンボリックリンクでないこと）を確認」を追加。worktree で依存を共有する場合は `node_modules` をリンクせず、ビルドはメインリポジトリでのみ行う。
