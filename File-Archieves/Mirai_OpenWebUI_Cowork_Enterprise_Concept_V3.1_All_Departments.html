01この仕組みで、何が変わる？

今まで「誰に聞けばいいか分からない」ことを、会社共通のAI窓口から始められるようにします。

😟

これまで

問い合わせ先を調べる → メールを送る → 状況を説明し直す → 返事を待つ。

😊

これから（目指す姿）

AI窓口で相談 → AIが社内資料を調べる → 必要なら本人に修復を提案 → 承認後に実行、難しければ担当者へ引き継ぐ。

この企画の一言まとめ：「社内問い合わせ」「書類作業」「PC修復」を別々の仕組みにせず、ひとつの画面にまとめます。

02社員ができるようになること

IT担当だけでなく、一般社員・現場担当・管理部門も使うことを想定しています。

💬

ITの相談

「VPNにつながらない」「Teamsの音が出ない」などを普通の言葉で質問。

📎

PC内のファイルを添付

エラー画像、PDF、Word、Excel、ログを選んで送信。アクセス権と情報区分を確認してから解析。

🩺

PCの状態を調べる

本人が許可した範囲で、設定や動作状況を調査して原因を絞り込みます。

🛠️

修復を提案・実行

「何を直すか」「困ることはないか」を説明。Y/N承認と権限確認のあとで操作。

📚

社内資料から答える

規程・手順書・FAQなどを、閲覧できる範囲だけ検索し、出典を示します。

🗂️

仕事の手伝い

ファイル整理、Excel集計、文章の下書き、決められた定型作業を支援。

「自動で何でも操作」はしません。 社用PCの操作は、端末管理者による配布、対象フォルダの制限、操作一覧、監査記録などが整った後に、許可されたものだけ実行します。

03AIがPCを修復するまでの5ステップ

例：「会社のプリンターから印刷できない」

🙋① 相談する症状を入力
必要なら写真添付
🔍② 調べるAIが許可範囲で
情報を確認
📝③ 提案する操作・影響・
戻し方を表示
✅④ 人が決めるY／Nの確認
必要なら管理者承認
🏁⑤ 確かめる修復結果の確認
履歴を残す
🧑‍💼 AIは勝手に修復しません。 利用者のY/Nに加え、操作によっては管理者の許可が必要です。修復後も正常に戻ったかを確認します。

11よくある質問

社員がYを押せば管理者権限の操作もできますか？

いいえ。Yは本人の承認です。管理者権限が必要な操作には、別途IT管理者の承認や正式な運用手順が必要です。

AIが勝手にPCの中身を全部読むことはありますか？

そうならない設計にします。本人が指定したファイルや許可フォルダと、部門・情報区分のアクセス権に限定します。

AIが間違った修復方法を出したら？

操作前に内容・影響・戻し方を表示し、許可済み操作のみ実行します。エラーや想定外の結果が出た場合は停止し、担当者へ引き継ぎます。

インターネットが使えない現場でも動きますか？

サーバへ接続できないと通常のAI相談は利用できません。現場通信やVPNの設計、障害時の電話等の代替手段が必要です。

Claude Coworkそのものを導入する計画ですか？

いいえ。Cowork型の使い勝手を参考にした独自の会社向け構想です。Open WebUIと専用サービスを組み合わせます。
