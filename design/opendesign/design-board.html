Design principles
1
次にやることが1つ

各画面に主ボタンを1つだけ置く。迷わせない。

2
AIの限界を隠さない

「MVP / ルールベース / デモデータ」を常時表示。

3
状態を設計する

空・読込・入力エラー・通信エラーを全画面に用意。

4
職務分離

自分の申請は承認できない。UIとAPIの両方で。

ログイン

デモアカウントを選ぶと、メールアドレスが入力されます。

パスワードは配備時に別途共有します。ログイン試行はレート制限されます。
本番想定の SSO（Entra ID）は MVP 対象外です。
設計メモ 状態 入力エラーはフィールド直下、認証エラーは上部の赤帯。送信中はボタンを `aria-busy` に。セキュリティ Cookie は HttpOnly / SameSite=Lax / Secure。ロールは API で判定。

共有フォルダにアクセスできないときの確認手順

申請者: 佐藤 健 · 申請: 2026-10-23 11:05 · 元案件: TKT-2026-0007

個人情報は自動で伏せ字になっています。 氏名・メール・電話・IP・資産番号・パスワード等。公開前に必ず内容を確認してください。
症状

共有フォルダを開くと「アクセスが拒否されました」と表示される。VPN接続は正常。

原因

共有フォルダのセキュリティグループに、利用者が所属していないため。

手順
  1. 共有フォルダの ACL を確認する
  2. 所属部署のセキュリティグループを追加する（権限付与の手続き）
  3. 利用者に再接続を依頼し、保存できることを確認する
